## Pendant une réunion

- Sélectionnez l’icône de bouclier à côté du nom de la réunion, en haut à gauche. Sélectionnez ensuite **Copier le lien** ou **Copier l’invitation**.
- Ou ouvrez **Participants** et sélectionnez **Inviter**.

Tant que vous êtes seul dans la réunion, une carte dans le coin affiche aussi le lien.

## Avant une réunion

- **Réunions planifiées :** ouvrez la réunion depuis **À venir** pour copier le lien ou l’invitation, ou pour l’ajouter à Google Agenda, à Outlook ou à n’importe quelle application d’agenda. Si Google Agenda est connecté, Google envoie les invitations pour vous quand vous enregistrez la réunion. Consultez [Planifier et répéter des réunions](/help/schedule-meetings).
- **Votre salle personnelle :** sélectionnez **Copier l’invitation** sur **Accueil** ou sur la page **Salle personnelle**.

## À propos du code secret

Le code secret fait partie du lien : les personnes qui ont le lien n’ont pas besoin de le saisir. Si vous ne partagez que l’ID de réunion, partagez aussi le code secret. L’invitation contient les deux. Les majuscules ne comptent pas dans un code secret.

Vous pouvez choisir votre propre code secret : de 2 à 10 lettres, chiffres ou @ - _ *. Saisissez-le quand vous planifiez une réunion, ou sélectionnez **Modifier** à côté du code secret sur la page de la réunion ou sur la page **Salle personnelle** ; **Générer** en crée un nouveau au hasard. Les personnes qui ont l’ancien lien ou l’ancien code secret auront alors besoin du nouveau : envoyez-leur la nouvelle invitation. Les personnes déjà dans la réunion à ce moment-là y restent.

> **Astuce :** une invitation est du texte brut, vous pouvez donc la coller dans un e-mail, un chat ou un événement d’agenda.
