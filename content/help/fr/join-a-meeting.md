## Rejoindre avec un lien

1. Ouvrez le lien de la réunion que vous avez reçu.
2. Dans l’aperçu, vérifiez qu’on vous verra et vous entendra :
   - Activez ou désactivez votre micro et votre caméra avec les boutons de l’aperçu.
   - Choisissez un **Micro**, un **Haut-parleur** et une **Caméra** en dessous.
   - Dites quelque chose. Quand l’indicateur bouge, le message **Votre micro fonctionne** s’affiche.
   - Sélectionnez **Écouter un son de test** pour vérifier votre haut-parleur.
3. Saisissez votre nom si vous n’êtes pas connecté.
4. Pour changer l’image que les autres voient quand votre caméra est éteinte, sélectionnez votre avatar à côté de votre nom. Sans compte, votre choix est conservé sur cet appareil pour la prochaine fois.
5. Si le lien ne contient pas le code secret, saisissez-le. Il figure dans l’invitation à la réunion, et les majuscules ne comptent pas.
6. Sélectionnez **Participer**.

Pour modifier autre chose avant (suppression du bruit, appuyer pour parler, les réglages de votre caméra, un arrière-plan), sélectionnez **Paramètres** sur l’aperçu. Ce sont les mêmes **Paramètres** que dans la réunion, et ils restent disponibles pendant que vous attendez d’être admis.

Pour rejoindre la réunion sans rien activer, sélectionnez **Participer sans audio ni vidéo**.

## Rejoindre avec un ID de réunion

Sur **Accueil** (ou, sans compte, sur la page d’accueil de {appName} ou la page de connexion), saisissez l’ID de réunion à 10 chiffres ou collez le lien (ou l’invitation entière) dans **ID de réunion ou lien**, puis sélectionnez **Rejoindre**.

Si la réunion a un code secret, il vous sera demandé. Les liens contiennent généralement le code secret : vous n’aurez donc pas à le saisir.

## Si un problème s’affiche

{appName} vérifie la réunion avant de l’ouvrir, et indique ce qui ne va pas juste sous le champ :

- **Un ID de réunion comporte 10 chiffres.** Vérifiez que vous les avez tous. Les espaces et les tirets ne comptent pas.
- **Aucune réunion ne correspond à cet ID.** Un chiffre est peut-être erroné. Vérifiez l’invitation, ou demandez à l’hôte de vous envoyer le lien.
- **Ce lien est destiné à un autre site.** C’est un lien vers une autre application de réunion, ou vers une autre copie de {appName}. Ouvrez-le plutôt dans votre navigateur.
- **L’ID de réunion de ce lien est incomplet.** Une partie du lien a été coupée. Copiez à nouveau le lien en entier.
- **La réunion est terminée, a été annulée, ou son lien a expiré.** Demandez un nouveau lien à l’hôte.
- **Trop de tentatives.** Après plusieurs ID erronés, patientez quelques minutes avant de réessayer.

Ouvrir un lien qui ne fonctionne pas affiche la même explication, avec un champ pour essayer un autre ID de réunion ou un autre lien.

## Si vous devez attendre

- **L’hôte n’a pas encore commencé.** Vous rejoindrez la réunion dès qu’il l’aura démarrée. Gardez la page ouverte.
- **La réunion a une salle d’attente.** Sélectionnez **Demander à participer**. L’hôte ou un co-hôte vous fera entrer.
- **La réunion est verrouillée ou complète.** Contactez l’hôte, puis réessayez.

## Participer sans compte

Si l’hôte autorise les invités, il vous suffit du lien et d’un nom. Connectez-vous plutôt si vous voulez que la réunion apparaisse dans votre liste **Précédentes**.
