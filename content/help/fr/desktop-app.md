{appName} fonctionne dans votre navigateur : vous n’avez jamais besoin de l’application pour rejoindre ou organiser une réunion. L’application pour Mac et Windows, c’est le même {appName} dans sa propre fenêtre, avec ce qu’un onglet de navigateur ne sait pas faire.

## Ce qu’elle apporte

- **Les liens de réunion s’ouvrent dans l’application.** Consultez « Ouvrir les liens de réunion » plus bas.
- **Couper le micro depuis n’importe quelle application.** Pendant une réunion, **Ctrl+Maj+A** (**⇧⌘A** sur Mac) coupe et réactive le micro quand une autre application est au premier plan. Modifiez ce raccourci, ou désactivez-le, dans **Paramètres → Application de bureau → Raccourci pour couper le micro**.
- **La zone de notification ou la barre des menus.** Démarrez ou rejoignez une réunion et, pendant celle-ci, coupez le micro ou quittez-la. Fermer la fenêtre y garde {appName}, sauf si vous désactivez **Garder {appName} dans la zone de notification** (**dans la barre des menus** sur Mac). Pour quitter, choisissez **Fichier → Quitter {appName}** (**{appName} → Quitter {appName}**, ⌘Q, sur Mac), ou **Quitter {appName}** dans le menu de l’icône de la zone de notification.
- **Google Agenda.** Google ne permet pas de le connecter dans les applications : **Connecter** ouvre donc votre navigateur sur l’écran d’autorisation de Google, et {appName} détecte quand vous avez terminé.
- **Le son de votre ordinateur** quand vous partagez votre écran, sous Windows.
- **Des rappels sans navigateur ouvert**, au moment choisi dans **Paramètres → Notifications**, avec **Rejoindre**.
- **Le chat non lu** dans le Dock ou la barre des tâches.
- **Mise à jour automatique**, en toute discrétion, installée au redémarrage.

## L’installer

Sur un Mac ou un PC Windows, **Télécharger pour Mac** ou **Télécharger pour Windows** (sur la page d’accueil, dans une carte affichée une fois sur **Accueil**, dans le menu de votre compte ou dans **Paramètres → Général**) récupère le programme d’installation pour votre ordinateur ; la page de téléchargement, [/download](/download), le fait aussi, et sur d’autres ordinateurs elle propose tous les programmes d’installation et des liens vers toutes les versions. Sur Mac, ouvrez le fichier `.dmg` et faites glisser {appName} dans Applications. Sous Windows, lancez le programme d’installation ; il installe l’application pour vous seul, sans demander de droits d’administrateur.

Votre ordinateur peut afficher un avertissement à la première ouverture :

- **Mac :** si votre copie de l’application n’est pas encore notariée, ouvrez-la une fois, puis allez dans **Réglages Système → Confidentialité et sécurité** et choisissez **Ouvrir quand même**. (Avant macOS 15, un clic droit sur {appName} dans Applications, puis **Ouvrir**, fonctionne aussi.)
- **Windows :** si « Windows a protégé votre ordinateur » s’affiche, choisissez **Informations complémentaires → Exécuter quand même**. Une application signée peut afficher ce message pendant peu de temps après la sortie d’une nouvelle version. Une application non signée l’affiche à la première ouverture, et ne s’ouvre pas du tout sur un PC où le Contrôle intelligent des applications est activé.

## Se connecter

La connexion avec une adresse e-mail et un mot de passe fonctionne dans l’application. **Continuer avec Google** et **Continuer avec GitHub** ouvrent votre navigateur : connectez-vous-y, sélectionnez **Continuer en tant que …**, et l’application termine votre connexion. Se déconnecter dans l’application laisse votre navigateur connecté, et inversement.

## Ouvrir les liens de réunion

Un lien de réunion s’ouvre d’abord dans votre navigateur. Une fois l’application connectée depuis ce navigateur, celui-ci sait que l’application est sur cet ordinateur, et la page de la réunion propose **Ouvrir dans l’application {appName}**, à côté de **Rejoindre dans ce navigateur**. Cochez **Toujours ouvrir les liens de réunion dans l’application** pour ne plus avoir à choisir.

Vous pouvez modifier ce choix dans **Paramètres → Général → Ouvrir les liens de réunion dans l’application de bureau {appName}**, dans ce navigateur : **Demander à chaque fois**, **Toujours** ou **Jamais**. Avec **Toujours**, la page de la réunion ouvre l’application aussitôt, avec **Rejoindre dans ce navigateur** au cas où elle ne s’ouvrirait pas.

Le code secret d’un lien l’accompagne jusqu’à l’application, sans passer par aucun serveur.

## Sur Mac

La première fois que vous partagez votre écran, macOS vous demande d’autoriser l’enregistrement de l’écran dans **Réglages Système → Confidentialité et sécurité → Enregistrement de l’écran**. Activez-y {appName}, puis quittez et rouvrez {appName}.

## Désinstaller

- **Mac :** quittez {appName} depuis la barre des menus, puis faites-le glisser d’Applications vers la Corbeille.
- **Windows :** **Paramètres → Applications → Applications installées → {appName} → Désinstaller**.
