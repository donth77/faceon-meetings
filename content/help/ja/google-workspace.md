{appName} の Google Workspace 用アドオンを使うと、普段ミーティングを計画している Google カレンダーと Gmail（パソコンのブラウザー）で {appName} を使えます。自分用のコピーを、{appName} の設定から Google アカウントに追加します。

## 追加する

1. {appName} で**設定 → カレンダー**を開き、**Google カレンダーと Gmail で使う {appName}** の **{appName} を追加**を選択します。
2. Google から、あなたのアカウントで Apps Script プロジェクトを作成・更新する権限を {appName} に与えるよう求められます。{appName} がこの権限を使うのは、アドオンを置いて最新の状態に保つためだけです。
3. **Apps Script で開く**を選択し、**デプロイ → デプロイをテスト → インストール**の順に選択します。Marketplace にないアドオンを Google でインストールするにはこの方法しかないため、この手順は一度だけご自身で行ってください。
4. Google カレンダーを開きます。初めて {appName} を使うとき、Google から許可を求められ、確認されていないアプリであるという警告が表示されます。これは Google の Marketplace に掲載されたものではなく、あなた専用のコピーだからです。**詳細**を選択し、{appName} に移動するリンク、**許可**の順に選択します。

Apps Script API がオフになっていると表示された場合は、[Apps Script の設定](https://script.google.com/home/usersettings)を開いて **Google Apps Script API** をオンにし、もう一度お試しください。Google アカウントが学校や会社のものである場合は、管理者が Apps Script を許可していない可能性があります。

コピーはあなたの Google アカウントでのみ動作します。ほかの人と共有しても、その人は使えません。その人は自分のコピーを追加できます。

## Google カレンダーでビデオ会議を追加する

1. 予定を作成するか、開きます。
2. **ビデオ会議を追加 ▾** を選択し、**{appName} meeting** を選びます。

予定に**参加**リンク、ミーティング ID、パスコードが追加されるため、招待した全員がそれを受け取れます。招待状は Google カレンダーからいつもどおり送信されます。

その後、{appName} は予定に合わせて動きます。予定を移動したり名前を変えたりするとミーティングもそれに合わせて変わり、予定を削除するとミーティングはキャンセルされます。繰り返しの予定では、すべての回で 1 つのミーティング ID を使い、1 回分を移動または削除すると {appName} でも同じように反映されます。変更は数分以内に {appName} に届きます。

この方法で作成したミーティングの {appName} のページには、Google カレンダーから作成されたことが表示され、予定を開けます。時刻は Google カレンダーで変更してください。パスコード、待機室、AI メモなどの {appName} の設定は、引き続き {appName} のページで変更します。**設定 → カレンダー**でも Google カレンダーを接続している場合でも、これらのミーティングの予定が 2 つ作られることはありません。

## カレンダーと Gmail のサイドパネル

Google カレンダーまたは Gmail の右側にある {appName} のアイコンを選択すると、次のことができます。

- 専用リンク付きの**ミーティングを開始**して、今すぐ参加するか、リンクを送る。
- 10 桁のミーティング ID でミーティングに**参加**する。
- 今週の**次のミーティング**を確認し、それぞれ**参加**する。
- **パーソナル ルーム**の招待状を表示して、コピーして送る。
- **設定**を開く。

## Gmail でメールにミーティングを挿入する

メールを作成中に、ウィンドウ下部のアドオン メニューを開き、**{appName} のミーティングを挿入**を選びます。新しいミーティング（必要ならタイトル付き）か、パーソナル ルームを選べます。招待状はカーソルの位置に挿入されます。

## アドオンが見られるもの

- **Google カレンダーでは、** {appName} のミーティングを追加した予定を、開いている間だけ見ます。ミーティングを同期させるため、その後そのカレンダーで変更された予定も確認しますが、{appName} に伝えるのは {appName} のミーティングがある予定だけです。
- **Gmail では、** 作成中のメールに挿入すると選んだテキストだけを扱います。メールを読むことはありません。

アドオンで作成したミーティングも、ほかのミーティングと同じようにミーティングの上限に数えられます（[ミーティングの上限](/help/meeting-limits)）。

## 更新と削除

{appName} はあなたのコピーを自動的に最新の状態に保ちます。Google でそれが許可されなくなった場合は、**設定 → カレンダー**で**アドオンを更新**を選択し、もう一度許可するよう求められます。

削除するには、**設定 → カレンダー**で**削除**を選択します。Google からも削除するには、その後 Apps Script で開いて**デプロイ → デプロイをテスト → アンインストール**の順に選択します。[Apps Script のプロジェクト](https://script.google.com/home)からプロジェクトを削除することもできます。

## スマートフォンの場合

Google のスマートフォン アプリではアドオンは動きませんが、参加情報は予定に含まれています。Google カレンダー アプリで予定を開き、リンクを選択すると参加できます。
