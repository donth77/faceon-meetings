## リンクから参加する

1. 受け取ったミーティングのリンクを開きます。
2. プレビューで、相手に見え、聞こえるかを確認します。
   - プレビューのボタンで、マイクとカメラのオンとオフを切り替えます。
   - その下で、**マイク**、**スピーカー**、**カメラ**を選びます。
   - 何か話してみます。メーターが動くと、**マイクは正常に動作しています**と表示されます。
   - **テスト音を再生**を選択して、スピーカーを確認します。
3. サインインしていない場合は、名前を入力します。
4. カメラがオフのときにほかの人に表示される画像を変えるには、名前の横のアバターを選択します。アカウントがない場合は、選んだものが次回のためにこのデバイスに保存されます。
5. リンクにパスコードが含まれていない場合は、入力します。パスコードはミーティングの招待状に記載されており、大文字と小文字は区別されません。
6. **今すぐ参加**を選択します。

ほかの設定（ノイズ抑制、プッシュ トゥ トーク、カメラの設定、背景）を先に変えるには、プレビューで**設定**を選択します。ミーティング中の**設定**と同じもので、入室の許可を待っている間も使えます。

何もオンにせずに参加するには、**音声とビデオなしで参加**を選択します。

## ミーティング ID で参加する

**ホーム**（アカウントがない場合は {appName} のトップ ページかサインイン ページ）で、10 桁のミーティング ID を入力するか、リンク（または招待状全体）を**ミーティング ID またはリンク**に貼り付けて、**参加**を選択します。

ミーティングにパスコードがある場合は、入力を求められます。リンクには通常パスコードが含まれているので、入力する必要はありません。

## 問題が表示された場合

{appName} はミーティングを開く前に確認し、問題があれば入力欄のすぐ下に表示します。

- **ミーティング ID は 10 桁です。** すべての桁がそろっているか確認してください。スペースやハイフンは関係ありません。
- **その ID のミーティングはありません。** 数字が 1 つ違っているかもしれません。招待状を確認するか、ホストにリンクを送ってもらってください。
- **そのリンクは別のサイトのものです。** 別のミーティング アプリ、または別の {appName} へのリンクです。ブラウザーで開いてください。
- **このリンクのミーティング ID は不完全です。** リンクの一部が切れています。リンク全体をもう一度コピーしてください。
- **ミーティングは終了したか、キャンセルされたか、リンクの有効期限が切れています。** ホストに新しいリンクを頼んでください。
- **試行回数が多すぎます。** 間違った ID を何度か入力した後は、数分待ってからもう一度お試しください。

使えないリンクを開いたときも同じ説明が表示され、別のミーティング ID やリンクを試すための入力欄が表示されます。

## 待つ必要がある場合

- **ホストがまだ開始していません。** ホストが開始するとすぐに参加できます。ページを開いたままにしてください。
- **ミーティングに待機室があります。** **参加をリクエスト**を選択します。ホストまたは共同ホストが入室を許可します。
- **ミーティングがロックされているか、満員です。** ホストに確認してから、もう一度お試しください。

## アカウントなしで参加する

ホストがゲストを許可していれば、必要なのはリンクと名前だけです。ミーティングを**過去**の一覧に表示したい場合は、サインインしてから参加してください。
