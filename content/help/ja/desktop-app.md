{appName} はブラウザーで動くので、ミーティングに参加したり主催したりするのにアプリは必要ありません。Mac と Windows 用のアプリは、同じ {appName} を専用のウィンドウで使えるようにしたもので、ブラウザーのタブではできないことも加わります。

## アプリでできること

- **ミーティングのリンクがアプリで開く。** 下の「ミーティングのリンクを開く」をご覧ください。
- **どのアプリからでもミュート。** ミーティング中は、ほかのアプリが前面にあるときでも、**Ctrl+Shift+A**（Mac では **⇧⌘A**）でミュートとミュート解除ができます。変更やオフにするには、**設定 → デスクトップ アプリ → ミュートのショートカット**を使います。
- **通知領域やメニューバー。** ミーティングを開始したり参加したりでき、ミーティング中はミュートや退出ができます。ウィンドウを閉じても {appName} はそこに残ります。残さないようにするには、**{appName} を通知領域に常駐させる**（Mac ではメニューバー）をオフにします。終了するには、**ファイル → {appName} を終了**（Mac では **{appName} → {appName} を終了**、⌘Q）を選ぶか、通知領域のアイコンのメニューで **{appName} を終了**を選びます。
- **Google カレンダー。** Google はアプリ内での接続を許可していないため、**接続**を選ぶとブラウザーで Google の同意画面が開きます。完了すると {appName} が検知します。
- **パソコンの音声**を、画面の共有と一緒に共有できます（Windows）。
- **ブラウザーを開いていなくてもリマインダー**が、**設定 → 通知**で選んだタイミングで、**参加**ボタン付きで届きます。
- **未読のチャット**を Dock やタスクバーに表示。
- **自動で更新**され、目立たずに更新し、再起動時にインストールします。

## インストールする

Mac または Windows PC で、**Mac 版をダウンロード**または **Windows 版をダウンロード**（トップ ページ、**ホーム**に 1 回だけ表示されるカード、アカウント メニュー、**設定 → 全般**にあります）を選ぶと、お使いのパソコン用のインストーラーを入手できます。ダウンロード ページ（[/download](/download)）でも入手でき、それ以外のパソコンではすべてのインストーラーとすべてのリリースへのリンクが表示されます。Mac では `.dmg` を開いて {appName} を「アプリケーション」フォルダーにドラッグします。Windows ではインストーラーを実行します。管理者権限を求められることはなく、あなたのアカウントにだけインストールされます。

初めて開くときに、パソコンから警告が表示されることがあります。

- **Mac:** アプリのコピーがまだ署名されていない場合は、「アプリケーション」フォルダーで {appName} を右クリックして**開く**を選ぶか、**システム設定 → プライバシーとセキュリティ → このまま開く**を選びます。
- **Windows:** 「Windows によって PC が保護されました」と表示された場合は、**詳細情報 → 実行**を選びます。署名済みのアプリでも、新しいバージョンが出た直後はしばらくこの表示が出ることがあります。署名されていないアプリは初回にこの表示が出るほか、スマート アプリ コントロールがオンの PC ではまったく開きません。

## サインインする

メールアドレスとパスワードでのサインインは、アプリ内でできます。**Google で続行**と **GitHub で続行**ではブラウザーが開きます。そこでサインインして **… として続行**を選ぶと、アプリでのサインインが完了します。アプリでサインアウトしてもブラウザーではサインインしたままで、その逆も同じです。

## ミーティングのリンクを開く

ミーティングのリンクは、まずブラウザーで開きます。そのブラウザーからアプリにサインインすると、このパソコンにアプリがあることをブラウザーが認識し、参加ページに **{appName} アプリで開く**が**このブラウザーで参加**と並んで表示されます。毎回選ばなくて済むようにするには、**ミーティングのリンクを常にアプリで開く**をオンにします。

この設定は、そのブラウザーの**設定 → 全般 → ミーティングのリンクを {appName} デスクトップ アプリで開く**で、**毎回確認する**、**常に開く**、**なし**から変更できます。**常に開く**にすると、参加ページからすぐにアプリが開き、開かなかった場合のために**このブラウザーで参加**が表示されます。

リンクに含まれるパスコードは、どのサーバーも経由せずにアプリに渡されます。

## Mac の場合

初めて画面を共有するとき、macOS から**システム設定 → プライバシーとセキュリティ → 画面収録**で許可するよう求められます。そこで {appName} をオンにしてから、{appName} を終了してもう一度開いてください。

## アンインストール

- **Mac:** メニューバーから {appName} を終了し、「アプリケーション」フォルダーからゴミ箱にドラッグします。
- **Windows:** **設定 → アプリ → インストールされているアプリ → {appName} → アンインストール**。
