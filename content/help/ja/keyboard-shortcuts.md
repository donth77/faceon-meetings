どこでも `?` を押すか、`Ctrl+/`（Mac では `⌘/`）を押すと一覧が表示されます。**設定**の**アクセシビリティ**にも、ミーティングの設定の中にも載っています。キーボードのないスマートフォンやタブレットでは、キーボードを使うまでメニューや設定に表示されません。

## ミーティング中

| 操作 | Windows と Linux | Mac |
| --- | --- | --- |
| ミュート / ミュート解除 | `Ctrl+D` または `Alt+A` | `⌘D` または `⌥A` |
| ミュート中に話す（**設定**の**オーディオ**で**プッシュ トゥ トーク**をオンにした場合） | `Space` キーを押し続ける | `Space` キーを押し続ける |
| ビデオの開始 / 停止 | `Ctrl+E` または `Alt+V` | `⌘E` または `⌥V` |
| 画面の共有 / 共有の停止 | `Alt+S` | `⌥S` |

## どこでも

| 操作 | Windows と Linux | Mac |
| --- | --- | --- |
| サイドバーの表示 / 非表示 | `Ctrl+B` | `⌘B` |
| キーボード ショートカットを表示 | `?` または `Ctrl+/` | `?` または `⌘/` |

入力欄に入力している間は、ショートカットは動作しません。

音声入力やスイッチ デバイスを使っている場合は、**設定**の**アクセシビリティ**で **1 キーのショートカット**をオフにしてください。オフにすると `Space` と `?` は何もしなくなり、`Ctrl+/`（`⌘/`）では引き続きこの一覧が表示されます。
