**設定**の**アカウント**を開きます。

## 写真と名前

カメラがオフのときは、ほかの人にあなたの写真が表示されます。

- アバターから 1 つ選ぶか、**シャッフル**を選択してほかの候補を表示します。ミーティングに参加するときに、名前の横のアバターを選択して変えることもできます。
- Google または GitHub でサインインした場合は、その写真を使うこともできます。
- **表示名**を変更します。ミーティングでほかの人に表示される名前です。

## サインイン方法

Google、GitHub、またはメールアドレスとパスワードでサインインでき、複数の方法を使うこともできます。

- **接続**を選択して Google または GitHub を追加します。アカウントと同じメールアドレスを使っている必要があります。
- 使わなくなった方法では**削除**を選択します。少なくとも 1 つは常に残ります。
- Google カレンダーを接続すると（**設定**の**カレンダー**）、Google もサインイン方法として接続されます。Google を削除すると、Google カレンダーの接続も解除されます。
- メールアドレスでもサインインするには**パスワードを設定**を、変更するには**パスワードを変更**を選択します。パスワードを変更すると、ほかのデバイスではサインアウトされます。

## データをダウンロードする

**データをダウンロード**を選択すると、{appName} があなたについて保存している、あなたが見られる情報を zip で入手できます。アカウント、主催するミーティングとその設定や招待者、過去 90 日間に主催または参加したミーティングに来た人、読むことができる AI メモ、フル ミーティングの主催のリクエストが含まれます。形式は JSON で、スプレッドシート（CSV）のコピー、Markdown 形式の AI メモ、内容を説明する README も付いています。チャット、音声、ビデオは含まれません。{appName} はそれらを保存しないためです。デバイスに保存された設定は、ブラウザー内に残ります。

## アカウントを削除する

**アカウントを削除**を選択します。ミーティング、メモ、アバターは完全に削除され、招待した人はあなたのミーティングに参加できなくなります。Google カレンダーを接続している場合は、先にそこで今後のミーティングがキャンセルされ、Google から招待した人に通知が届きます。その後、{appName} はカレンダーへのアクセス権を手放します。過去のミーティングはカレンダーに残ります。最近サインインしていない場合は、先にもう一度サインインするよう求められます。

アカウントと一緒に削除されるものと、一定期間残るものについては、[プライバシー ポリシー](/privacy)で説明しています。
